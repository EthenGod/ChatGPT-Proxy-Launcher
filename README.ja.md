# ChatGPT 軽量ランチャー

Windows x64 向けの非公式 ChatGPT ランチャーです。ChatGPT 用のプロキシ、デスクトップショートカット、サインイン時の自動起動を設定できます。アプリを起動するとランチャーは終了します。システムプロキシは変更しません。

## クイックスタート

[![小黑盒 | 簡単な使い方：中国語](https://img.shields.io/badge/Xiaoheihe-Tutorial_in_Chinese-1F2328?style=for-the-badge)](https://www.xiaoheihe.cn/app/bbs/link/196448409)

**始める前に：** キーボードの **Windows ロゴキー（Win）** を押し、`ChatGPT` と入力してください。ChatGPT デスクトップアプリを見つけて開ければ、次へ進めます。ブラウザー版だけを使っている場合は、先に [ChatGPT 公式ダウンロードページ](https://chatgpt.com/download/)から Windows 版をインストールしてください。本ツールはアプリの起動方法を設定するものです。

どちらの方法でも同じ設定ツールが開きます。**どちらか一方を選んでください。方法 1 を推奨します。**

### 方法 1：PowerShell の 1 行コマンドで開く（推奨）

1. **Win** を押して `Windows PowerShell` と入力し、検索結果の **Windows PowerShell** をクリックします。Windows 付属のバージョンで使えます。PowerShell 7 を使う場合は、[公式リリースページ](https://github.com/PowerShell/PowerShell/releases/latest)からダウンロードできます。
2. 下のコード欄の右上にあるコピーアイコンを押します。見当たらない場合は、`irm` から末尾の `iex` まで選択し、**Ctrl+C** でコピーしてください。

   ```powershell
   irm https://raw.githubusercontent.com/EthenGod/ChatGPT-Proxy-Launcher/master/setup.ps1 | iex
   ```

3. PowerShell のウィンドウをクリックし、**Ctrl+V** で貼り付けて **Enter** を押します。
4. バージョンの取得、ダウンロード、検証の進捗が表示されます。**ChatGPT ランチャー設定** が開いたら、下の **開いた後の設定** へ進んでください。PowerShell は閉じずに残します。設定ツールの終了後、一時ファイルを削除して完了メッセージを表示します。

エラーが出て設定ツールが開かない場合は、方法 2 を使ってください。

### 方法 2：手動でダウンロードして開く

[![GitHub | 最新版のダウンロードページ](https://img.shields.io/badge/GitHub-%E6%9C%80%E6%96%B0%E7%89%88%E3%82%92%E9%96%8B%E3%81%8F-2563EB?style=for-the-badge&logo=github)](https://github.com/EthenGod/ChatGPT-Proxy-Launcher/releases/latest)

1. 上の青いボタン、または[ダウンロードページへのリンク](https://github.com/EthenGod/ChatGPT-Proxy-Launcher/releases/latest)をクリックします。下へスクロールして **Assets** を探します。ファイル一覧が隠れている場合は **Assets** をクリックしてください。
2. **`ChatGPTLauncherSetup.exe`** をクリックします。必要なのはこのファイルだけです。もう一方の EXE やソース ZIP は不要です。
3. ダウンロードが終わったら、ブラウザーで **Ctrl+J** を押します。`ChatGPTLauncherSetup.exe` の横のフォルダーアイコン、または **フォルダーに表示** をクリックします。
4. 開いたフォルダーでファイルをダブルクリックします。**ChatGPT ランチャー設定** が開いたら、次の手順へ進みます。

### 開いた後の設定（両方の方法で共通）

初期状態では Windows の表示言語に合わせます。简体中文、English、日本語に対応し、一致する言語がなければ中国語になります。右上で言語を変更するか、**システムに従う** を選べます。選択は自動保存され、再配置は不要です。

1. **起動するタイミングを選ぶ。** サインインするたびに ChatGPT を開く場合は、**Windows へのサインイン時に起動** をオンのままにします。手動で開きたい場合はオフにします。
2. **デスクトップにアイコンを置く。** 後から簡単に起動したい場合は、**デスクトップにショートカットを作成** をオンにします。不要ならオフのままで構いません。灰色の **メインウィンドウを表示せずに起動（利用不可）** は現在使えないため、飛ばしてください。
3. **必要に応じてプロキシを設定する。**
   - 普段のプロキシソフトを開いたまま、設定ツールに戻り、**指定したプロキシを使う** をオンにします。
   - ソフトが提供するプロトコルを選びます。例えば HTTP ポートなら **HTTP** を選びます。同じパソコンでプロキシを動かしている場合、**アドレス** は `127.0.0.1` のままにします。
   - 空の **ポート** 入力欄をクリックします。数字が入った場合も、ソフトの設定と一致するか確認してください。番号が違う場合や空のままの場合は、プロキシソフトの設定で選んだプロトコルのポート番号を調べ、ここに入力します。
   - **Codex の .env も設定する（推奨）** は初期状態でオンです。同じプロトコル、アドレス、ポートを使います。隣の **?** にマウスを合わせると説明が出ます。不要ならオフにしてください。
4. **保存する。** **起動オプションのプレビュー** は自動更新されるため、入力は不要です。初回は **詳細設定** を飛ばして、右下の **配置して保存** を押せます。配置済みの場合は **変更を保存** と表示されます。
5. **配置完了のメッセージが出た場合：** **OK** を押して Windows の **スタートアップ アプリ** 設定を開きます。**ChatGPT** を **オフ**、**ChatGPT Launcher** を **オン** にしてください。保存した設定でサインイン時に起動するための確認です。
6. **設定ツールを閉じる。** **保存済み** になったら **完了** を押します。もう一度配置する必要はありません。方法 1 では、PowerShell が一時ファイルを削除し、Star のお願いを表示します。何かキーを押すか 10 秒待つと、プロジェクトのページを開いて終了します。ページを開きたくない場合は、PowerShell のウィンドウを直接閉じてください。ダウンロード、検証、削除に失敗した場合は、エラーを表示したまま残ります。
7. **起動してみる。** 保存だけでは ChatGPT は開きません。デスクトップショートカットを作成した場合は、**ChatGPT Launcher** をダブルクリックします。ChatGPT がすでに動いている場合は、先に完全に終了してください。サインイン時の起動だけを有効にした場合は、次のサインイン時に起動を試みます。

旧版のショートカットは **ChatGPT Proxy Launcher** という名前の場合があります。更新後の設定ツールで保存すると、本ツールが管理するショートカットは新しい名前に移行されます。

**後から設定を変える場合：** 方法 1 のコマンドをもう一度実行するか、方法 2 でダウンロードした設定ツールを開きます。変更して **変更を保存** を押してください。

**Codex の .env 設定を有効にした場合：** 先に ChatGPT と Codex での作業を保存してください。保存後、ChatGPT デスクトップアプリ全体の終了を試み、最大 10 秒待機します。下のメッセージに従って ChatGPT を開き直してください。完全な終了を確認できないと表示された場合は、先に手動で完全に終了します。`%USERPROFILE%\.codex\.env` の `all_proxy`、`ALL_PROXY`、`HTTP_PROXY`、`HTTPS_PROXY` を更新し、不足する変数を追加します。ほかの内容は残します。これはランチャーの引数とは独立した設定で、Chat には適用されません。オプションをオフにしても既存の内容は削除せず、以後の更新だけを止めます。プロキシのポートを変えた場合は再保存してください。Codex の再接続問題を改善する可能性はありますが、接続の成功は保証しません。

## 使い方

翻訳の追加や改善は[コミュニティ翻訳ガイド](docs/translating.ja.md)を参照してください。言語ファイルを編集するだけで、C++ の変更は不要です。

### ChatGPT の起動後にプラグインや別のプログラムを開く

1. 新しい設定ツールで左下の **詳細設定** を開き、**ChatGPT の起動後に開く** を探します。
2. **プログラムを追加…** を押し、普段プラグインを起動するファイルを選んで **開く** を押します。対応形式は下表のとおりです。ツールはショートカットを作成します。既存のショートカットを選んだ場合はコピーします。元のファイルは移動せず、同名ファイルも上書きしません。
3. 初めて使う場合や古いランチャーから更新する場合は、**戻る → 配置して保存**、配置済みなら **変更を保存** を押します。その後は本ツールのデスクトップショートカットやサインイン時の自動起動を使うと、追加したプログラムも開きます。ChatGPT 公式アイコンからの起動では実行されません。
4. 登録内容を確認・解除するには、**詳細設定 → 起動フォルダーを開く** を押し、対象のファイルをフォルダーから移します。対応ファイルを直接入れることもできます。ほかのファイルに依存するプラグインは、元の場所を維持できるショートカットを推奨します。

このフォルダーは `%LOCALAPPDATA%\ChatGPTProxyLauncher\StartupApps` です。Windows のスタートアップフォルダーとは別です。直下にあるローカルプログラム、スクリプト、それらへの通常のショートカットだけを処理します。ChatGPT のプロセス作成に成功するたびに起動を試みます。ウィンドウの読み込み完了や、従来方式の追加プログラムがすでに実行中かどうかは確認しません。

| ファイル | 起動方法 |
| --- | --- |
| `.exe`、`.lnk` | プログラムを直接起動するか、対応するプログラム・スクリプトへの通常のショートカットを使います。 |
| `.bat`、`.cmd`、`.ps1` | バッチは cmd、PS1 は Windows PowerShell を使用し、パソコンの実行ポリシーに従います。バッチの引数はファイル内に記述してください。 |
| `.vbs`、`.js`、`.wsf` | Windows Script Host を使用します。対応するスクリプトエンジンが必要です。ここでの JS は従来の Windows JScript です。 |
| `.py`、`.pyw` | Python が必要です。`.py` は `python.exe`、コンソールなしの `.pyw` は `pythonw.exe` を使います。 |
| `.cjs`、`.mjs` | Node.js（`node.exe`）が必要です。Node.js で普通の `.js` を実行するプラグインは、既存の起動ショートカットを選んでください。 |
| `.jar` | Java（`java.exe`）が必要です。`java -jar` で実行できるファイルに限ります。 |

Python、Node.js、Java が見つからない場合は、インストール済みで、そのフォルダーが Windows の `PATH` に含まれていることを確認してから設定ツールを開き直してください。インタープリターの EXE を直接指定し、引数でスクリプトを渡す既存のショートカットも使えます。Python 仮想環境や、特定バージョンが必要なプラグインにも対応できます。本ツールは実行環境を自動インストールしません。

### その他の設定

- **バージョン：** タイトル横に設定ツール自身、下の行に配置済みランチャーのバージョンを表示します。起動時と保存後に確認します。バージョン情報のない旧版は不明と表示します。新しい設定ツールで保存すると、新版の情報を読み取れます。これはローカルの配置情報で、オンラインの更新確認ではありません。
- **プロキシ検出：** `127.0.0.1` または `localhost` の HTTP・SOCKS5 に対応します。Clash Verge Rev、FlClash、Clash for Windows、v2rayN の一般的な設定を検出できます。ポートが見つかっても接続の成功を意味しません。新しい起動オプションを使うには、動いている ChatGPT を完全に終了し、ランチャーから開き直してください。
- **デスクトップショートカット：** 初期状態では作成しません。オンで保存するとリンク先と引数を更新します。オフにして保存すると、本ツールが管理するデスクトップショートカットだけを削除します。
- **ウィンドウを表示しない起動：** 現在は使えず、スイッチは無効です。以前の選択は維持しますが、メインウィンドウを非表示にできる保証はありません。
- **タスクバーアイコン：** ChatGPT 更新後に空白になった場合は、本ランチャーから一度起動してみてください。スタートメニューのショートカットが ChatGPT のものと確認できた場合だけ修復を試みます。タスクバーに別途ピン留めしたショートカットは対象外です。[アイコン修復の説明](docs/taskbar-repair.ja.md)を参照してください。

## コマンドライン

手動で使う場合は、同じリリースページから単体の `ChatGPTProxyLauncher.exe` をダウンロードします。次の例のポート番号は、プロキシソフトに表示された値に置き換えてください。

```cmd
ChatGPTProxyLauncher.exe --proxy-server=http://127.0.0.1:7897
```

コマンドプロンプトで `--launcher-check` を最初の引数にすると、アプリのパスと渡される引数を確認できます。ChatGPT の起動やショートカットの変更は行いません。

```cmd
ChatGPTProxyLauncher.exe --launcher-check --proxy-server=http://127.0.0.1:7897 > check.txt
```

`check.txt` には実際のパスと完全な引数が入ります。共有前に個人のパス、非公開のプロキシアドレス、認証情報を取り除いてください。

## ソースからビルド

**スクリプト・プラグイン作者向け：** v1.1.0 以降は、バックグラウンドでの配置、配置情報の照会、起動確認と回数制限付き再試行に対応します。[開発者ガイド（中国語）](docs/developer-guide.md)と[自動化の使い方（中国語）](docs/automation-usage.md)を参照してください。オンラインコマンドには、対応するスクリプトと EXE の GitHub 公開が必要です。通常の利用では上の設定ツールの手順を使ってください。

Visual Studio 2022 Build Tools の C++ ツールと Windows SDK が必要です。プロジェクトのルートで実行します。

| コマンド | 用途 |
| --- | --- |
| `cmd /c build.cmd` | 両方の EXE を `outputs/` に生成します。 |
| `cmd /c tests\test-build.cmd` | 再ビルドと隔離テストを実行します。ChatGPT の起動や実際の自動起動設定の変更は行いません。 |
| `cmd /c release.cmd` | ビルド、テスト、ローカル公開用ファイルの作成を行い、`Releases/vバージョン/` に保存します。GitHub にはアップロードしません。 |
