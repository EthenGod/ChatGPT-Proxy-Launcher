# 项目审查与性能优化

## 目标与边界

- 减少配置器的重复进程扫描、文本复制和局部绘制开销。
- 减少启动器创建进程时的临时分配。保留启动后退出，不增加常驻进程或跨次缓存。
- 保留代理识别条件、参数原样传递、文件校验、冲突保护及保存失败回滚。
- 统一构建环境入口和文件格式约定。内部记录放在此处，README 继续面向用户。
- 不更改真实用户配置，不关闭真实 ChatGPT，不清理已有备份或重打旧 Release。

## 检查与验证

- 基线为 `8692fb2`。先运行完整隔离测试，再比较同一组合成数据的耗时。
- 代理检测检查扫描次数、同次缓存边界、配置解析结果及异常输入。
- 启动器检查分配次数、路径、工作目录、引号与参数边界。进程创建只使用隔离测试子进程。
- 界面检查局部重绘、滚动、主题、缩放、按钮键盘行为和空闲计时器。
- 最后运行完整构建、隔离测试和静态分析。统计与本机原始报告保存在 `work/`。

## 风险

- 缓存仅在一次检测内有效。下次点击须重新读取，避免代理工具重启后沿用旧 PID。
- 减少绘制不能漏掉圆角边缘，也不能恢复原生按钮绘制。完整绘制与局部绘制应得到相同图像。
- 合成测试不代表真实应用启动、网络连接或第三方代理的端到端速度。

## 实施结果

审查日期：2026-11-11。对照提交 `8692fb2`。版本号和旧 Release 保持原样。

| 环节 | 原实现 | 本次处理 |
| --- | --- | --- |
| 代理进程发现 | 按工具名重复获取进程快照，完整检测路径为 10–11 次 | 每次检测最多获取一次；同一进程的路径查询也只做一次 |
| 代理配置解析 | 复制整份 YAML，再逐行创建和裁剪字符串 | 使用 `string_view` 读取原文本；保留重复键、多文档和非法端口的拒绝规则 |
| v2rayN 配置发现 | 安装根目录与本地配置目录相同时可能读取两遍 | 合并相同目录；没有可核对的监听端口时跳过配置读取 |
| 快捷方式读取 | 同时保留三个 32768 字符缓冲区和一个 1024 字符缓冲区 | 复用一个缓冲区，临时缓冲区总容量从 194 KiB 降到 64 KiB |
| 启动进程 | 分别分配命令行和工作目录缓冲区 | 合并为一次分配；已有工作目录时不再复制目录 |
| 界面刷新 | 小范围刷新也申请整个客户区的缓冲区 | 按 `rcPaint` 申请；完全位于裁剪区域外的圆角不再构造绘图对象 |

代理检测的文件、快照和进程句柄改为作用域内自动释放，避免内存分配异常时遗漏关闭。未引入后台服务、持久缓存、日志或第三方运行库。

项目规范新增 `.editorconfig` 和 `.gitattributes`，约定编码、缩进及换行，不进行全项目重排。`tools/msvc-env.cmd` 统一定位 C++ 工具链。`tests/analyze.cmd` 提供独立的静态分析入口。发布源码清单已同步，51 个文件齐全且无重复；构建产物、本机数据和旧 Release 不进入源码包。

## 测量与验收

- YAML：4194227 字节的合成配置，每轮解析 20 次。新旧程序使用相同的 MSVC `/O1 /MT` 选项，交替测量 5 轮。单次解析耗时中位数由 **37.245 ms 降至 2.821 ms**，约减少 92%。旧版范围 34.692–37.911 ms，新版范围 2.436–3.388 ms。数据仅包含虚构节点。
- 上述数值只衡量 YAML 解析，不包括磁盘读取、进程查询、网络或 ChatGPT 启动。缓冲区容量也不等于整个程序的内存占用。
- 滚动：用同一版隔离界面测试交替运行新旧绘制代码，每轮滚动 301 次，共 3 轮。旧版 1838–1913 ms，新版 1909–1933 ms，中位数为 1881/1914 ms。未确认整体滚动提速；保留此结果，不把局部缓冲区优化当作帧率提升。
- 三张基线图像逐像素一致：深色 150%、代理选项展开后的 200% 窄窗口、短窗口滚动状态。新增分块与完整绘制对比，覆盖浅色、深色、高对比度、100–200% 缩放和滚动；全部一致。
- 完整构建与隔离测试通过。覆盖原样传参、随机参数、分配失败、附加程序、任务栏链接、部署回滚、`.env` 合并、自启状态、应用退出替身、下载与清理、按钮键盘行为。补充的局部绘制测试单独复测通过。下载测试在 Windows PowerShell 5.1 和 PowerShell 7 中均通过。
- 8 个正式 C++ 源文件通过 `/W4 /WX /analyze` 静态分析，退出码为 0。
- 检查源码清单、忽略规则、差异空白和常见敏感信息标记。v1.0.5、v1.0.6 的原有附件通过各自 SHA-256 清单核对。保留 `work/` 中的备份，不批量删除。

可重复运行：

```powershell
cmd /c tests\test-build.cmd
cmd /c tests\analyze.cmd
.\work\proxy-tests.exe --benchmark
```

原始测试输出和对照测量放在被忽略的 `work/`。没有验证真实 ChatGPT 启动时间、自启、联网或应用退出，也没有覆盖用户已部署的程序。

绘制接口依据：[BeginBufferedPaint](https://learn.microsoft.com/en-us/windows/win32/api/uxtheme/nf-uxtheme-beginbufferedpaint)、[RectVisible](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-rectvisible)。像素对比用于检查本项目的实际裁剪结果。
