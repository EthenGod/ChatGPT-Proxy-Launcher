# 多语言设计

## 目标与范围

界面、帮助、错误提示、启动器通知和 PowerShell 下载提示共用语言目录。首批提供简体中文、英语、日语。社区添加语言不改 C++ 代码。机器接口字段、错误代码、参数、文件名和管理标记不翻译。

## 结构

- `locales/languages.json` 显式登记语言文件。每份 UTF-8 JSON 保存语言标识、本地名称、字体和文本。
- 中文是基准。文本使用稳定的语义键；带变量的句子使用 `{path}` 等命名占位符，不拆成多个片段翻译。
- 构建脚本检查键、占位符、语言标识和文件格式，再生成原生静态表及 PowerShell 内嵌文本。缺失译文回退中文。正式内置的三种语言必须完整。
- 两个 EXE 使用同一个轻量模块。查询文本不读取磁盘、不分配内存。命名格式化只在需要组合变量时分配字符串。
- 配置器右上角使用自绘语言按钮和主题一致的菜单。切换只刷新文本、字体及布局，不覆盖输入或改变启动参数。保存与检测期间暂不切换语言，避免工作线程混用语言。
- 选择保存到当前用户偏好。默认跟随 Windows 界面语言，没有匹配语言时用中文。菜单保留“跟随系统”和手动选择。启动器及 PowerShell 使用同一偏好。

## 验收与边界

检查三种语言的界面、弹窗、帮助、错误及下载提示。覆盖浅深色、键盘操作、最小窗口和 100% 至 200% 缩放。验证切换后输入、选项和未保存状态保留。检查占位符错误、缺失译文和未知语言的回退行为。

不引入常驻服务、在线翻译或运行时依赖。构建和测试仍在隔离目录执行。Windows 自带对话框按钮和系统错误详情受已安装的系统语言资源影响；应用自己的说明使用所选语言。首批布局按从左到右设计，新增从右到左语言还需要适配布局。

## 验证记录

- 三种语言共用 251 个文本键。中文、英语、日语完整性校验通过。部分社区翻译使用中文回退；未知键、重复键、错位占位符和格式错误会阻止生成。
- 完整隔离测试通过。语言切换保留字段、参数预览和未保存状态；语言偏好写入失败、检测中和保存中均有覆盖。UI 检查覆盖三种语言、浅深色、高对比度、最小窗口及 100%、150%、200% 缩放。
- Windows PowerShell 5.1 和 PowerShell 7 的语言、下载校验、进度、清理和退出测试通过。网络、设置、浏览器和真实应用退出使用替身。
- 10 万次文本查询与语言匹配未发生堆分配。该结果只说明内存查询开销，不代表完整冷启动耗时。发布源码清单包括所有登记语言，不扫描任意本机文件。
