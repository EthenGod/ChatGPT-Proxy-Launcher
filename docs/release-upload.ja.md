## 更新内容

- 設定画面を刷新しました。中国語、英語、日本語と、ライト・ダークテーマに対応します。プロキシをオンにするとポートを一度検出します。通知をクリックすると検出元を確認できます。
- 詳細設定で追加プログラムの一覧と、ランチャーの連携規格に対応するプログラムを確認できます。
- WebView2 がない場合、PowerShell でインストールするか、従来の互換画面を使うかを選べます。設定ツールをダブルクリックすると自動で互換画面が開きます。
- PowerShell の既定は正式版のみです。`-Channel Preview` でテスト版も対象にでき、`-Branch` でブランチ、`-Tag` でリリースを指定できます。

## 保存前の注意

サイレント起動は引き続き利用できません。Codex にプロキシ設定を適用する場合は、ChatGPT での作業を先に保存してください。設定ツールは ChatGPT の終了を試みます。必要な場合は、手動で終了して開き直すよう案内します。
