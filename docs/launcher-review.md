# 启动器复查范围

目标：原生、轻量、启动后退出；参数原样传给显式路径的 ChatGPT，不通过命令解释器，不修改系统代理。

## 实现约定

- 从 Windows 当前用户的包信息选择数字版本最高的主应用包，排除资源包和其他身份。
- 包列表或路径变化最多重查 3 次；权限等错误立即返回，缺少最高版本程序不回退。
- 缓冲区按需要分配，成功路径直接返回；正常运行不写日志、不显示额外窗口。
- `--launcher-check` 仅检查路径与参数，不启动 ChatGPT。

## 验证

运行 `cmd /c build.cmd` 和 `cmd /c work\test-build.cmd`。测试覆盖包筛选、更新竞态、内存分配失败、错误码、工作目录、参数原样传递和长度边界。测试替换接口只编入隔离测试程序。

本次构建、MSVC 静态分析和隔离测试通过。补测了顶层入口分流、成功启动后的句柄释放、1,000 次模拟调用的内存释放及 500 组随机参数边界。实际安装 EXE 的只读检查通过；重编译文件除构建时间戳外与原 EXE 一致，保留原程序。

## 边界

包查询与进程创建不是原子操作，最后检查后遇到卸载仍可能返回启动错误。隔离测试不证明真实商店更新、登录自启、静默效果或网络连接成功。
