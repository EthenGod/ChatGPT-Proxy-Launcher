**第一次使用请先看[快速开始](https://github.com/EthenGod/ChatGPT-Proxy-Launcher/blob/v1.2.5/README.md#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)。** 教程中的一行 PowerShell 命令默认下载并打开最新正式版配置器。手动下载和首次设置也有分步说明。

**从旧版升级**，双击打开新版配置器，点 **保存更改** 即可更新启动器。[直接下载 v1.2.5 配置器](https://github.com/EthenGod/ChatGPT-Proxy-Launcher/releases/download/v1.2.5/ChatGPTLauncherSetup.exe)

如果开启了 **应用于 Codex 环境变量**，请先保存 ChatGPT 和 Codex 中的工作。保存设置后，配置器会尝试退出 ChatGPT。

## ✨ 更新内容

- 保存弹窗的标题与正文之间增加了留白。

## 🛠️ 修复内容

- 保存后，即使底部提示换成多行，提示文字和「查看详情」也会上下居中。
- 英文和日文的长设置名称换行时，旁边的帮助按钮保持居中。

## ⚠️ 已知问题

- **静默启动** 暂不可用，启动时仍可能看到 ChatGPT 主窗口。
- 如果配置器提示 ChatGPT 仍在运行，请手动完全退出，再从 **ChatGPT Launcher** 快捷方式打开。
