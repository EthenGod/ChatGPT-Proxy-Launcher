## What's new

- The configurator and launcher are smaller downloads. Checking the launcher uses less memory when you save an existing configuration again.
- The preview updates faster when you enter a long set of launch arguments.

## Fixes

- The status icon in the lower left keeps its shape as it moves when you switch languages. The **Save changes** button changes brightness smoothly when you adjust an option.
- Clicking Save several times in quick succession saves once. If you try to close the window during a save, it stays open so the write can finish.

## Before saving

Silent startup remains unavailable. When applying proxy settings to Codex, save your work in ChatGPT first. The configurator will try to quit ChatGPT and will prompt you if you need to quit and reopen it manually.
