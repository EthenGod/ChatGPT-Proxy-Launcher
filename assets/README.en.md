# ChatGPT icon

`ChatGPT.ico` was extracted from the `ChatGPT.exe` icon resource in the installed ChatGPT Windows app (package version 26.1007.2314.0). The original images are unchanged. It contains 16, 20, 24, 32, 40, 48, 64 and 256 pixel sizes.

The icon identifies the app being launched. Rights to the ChatGPT name, logo and icon belong to OpenAI. The icon is not covered by this project's GPL-3.0-only code license. This is an unofficial launcher, not a product made, approved or endorsed by OpenAI.

The same icon is embedded in both EXEs during the build. Generated shortcuts use the first icon in the deployed launcher EXE. No separate ICO file or fixed ChatGPT installation path is required.
