# ChatGPT 图标

`ChatGPT.ico` 提取自已安装的 ChatGPT Windows 应用（应用包版本 26.1007.2314.0）的 `ChatGPT.exe` 图标资源，保留原有图像，未重新绘制。包含 16、20、24、32、40、48、64、256 像素尺寸。

该图标用于标识启动目标。ChatGPT 名称、标志及图标的相关权利归 OpenAI 所有；图标不在本项目代码的 GPL-3.0-only 授权范围内。本项目是非官方启动器，不代表 OpenAI 出品、认可或背书。

构建时将同一图标嵌入两个 EXE。生成的快捷方式引用部署后的启动器 EXE 的第一个图标，不需要旁置 ICO 文件或固定 ChatGPT 安装路径。
