# ChatGPT アイコン

`ChatGPT.ico` は、インストール済みの ChatGPT Windows アプリ（パッケージバージョン 26.1007.2314.0）の `ChatGPT.exe` から抽出したアイコンです。元の画像は変更していません。16、20、24、32、40、48、64、256 ピクセルの画像を含みます。

このアイコンは、起動対象のアプリを示すために使用しています。ChatGPT の名称、ロゴ、アイコンに関する権利は OpenAI に帰属します。アイコンは、本プロジェクトのコードに適用される GPL-3.0-only ライセンスの対象外です。本プロジェクトは非公式のランチャーであり、OpenAI が制作、承認、推奨したものではありません。

ビルド時に、同じアイコンを両方の EXE に埋め込みます。作成したショートカットは、配置済みランチャー EXE の最初のアイコンを参照します。別の ICO ファイルや固定の ChatGPT インストール先は不要です。
